**Publish manually on Google Business Profile → Updates / News.**

4WP TODO brings team tasks and checklists into WordPress using native Gutenberg notes — kanban lists in wp-admin, a frontend overlay for your team, and REST for the 4WP plugin ecosystem.

**Version 1.0.0** — Initial WordPress.org release: admin Dashboard and TODO Lists kanban, frontend task overlay, Settings (visibility rules, admin bar), Gutenberg `forwp/todo-tasks` block, and Integration API for other plugins.

- Plugin: https://4wp.dev/
- WordPress.org: https://wordpress.org/plugins/4wp-todo/ (when live)
