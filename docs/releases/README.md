# Release notes (4WP)

Draft copy for channels **outside** WordPress.org — Google Business Profile, social, newsletter, [4wp.dev](https://4wp.dev/).

WordPress.org users see `readme.txt` (`== Changelog ==`).

## Workflow (every release)

1. Ship the version (Git tag; SVN `trunk` + `tags/{version}` when listed).
2. Add `docs/releases/{version}.md` (English; short + long post blocks).
3. Adapt into each channel as needed.
4. **Publish on Google Business Profile → Updates / News** (manual — agent reminds, does not post).

Do **not** skip step 4 for “small” or SVN-only releases.

## Not shipped in wp.org ZIP

This `docs/` tree is excluded via `.distignore`.
